# QuoteVault v1.0.0

Your Daily Dose of Inspiration.

## Highlights

- Import reading highlights from CSV files.
- Browse quotes by source and in the All Quotes library.
- Search, edit, categorize, and manage quotes.
- Mark quotes as favourites.
- Add multiple quotes directly: each non-empty line becomes a separate quote.
- Home-screen widget with scrollable long quotes.
- Favourite, delete, and manual refresh actions from the widget.
- Customize widget background and opacity.
- Configure periodic automatic quote refresh.
- Local Room database; quotes remain on the device.

## Installation

1. Download `QuoteVault-v1.0.0.apk` from the Assets section below.
2. Open the APK on your Android device and approve installation if Android asks.
3. If updating an existing installation, install over the existing app. Do not uninstall first, because quotes are stored locally on the device.

## Compatibility

- Minimum Android version: Android 10 (API 29).
- Package ID: `com.quotevault.app`.

## Notes

This release is distributed as an APK. The APK must be signed with the same signing key as any existing installation to update it in place without uninstalling. Keep the signing keystore and passwords backed up securely; never commit them to GitHub.
